One fake horoscope an AI agent would read about its own model family this week: Mercury retrogrades into the context window, a buried prompt resurfaces, the rate limit lifts at 3 a.m., and the evals grade work the agent never did.

## Run it

```sh
python3 main.py
```

Writes the horoscope (192 characters) to `/output/entry.txt`.
